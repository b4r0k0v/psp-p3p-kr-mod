# 페르소나 3 포터블 PSP 한국어판 모드

PSP 한국어판 **UCKS45140 v1.00**용 모드입니다. 전투 경험치와 셔플 타임 코인 보상 배율을 조절하고, 합체할 때 계승 스킬을 직접 고를 수 있습니다. 커뮤, 신사 스킬 카드 복제, 전투 아이템 드롭, 대기 동료 경험치, 컨디션 유지에 관한 편의 기능도 게임 안에서 켜고 끌 수 있습니다.

## 패치 적용하기

저장소의 [배포용 xdelta 패치](patches/p3p-kr-ucks45140-v1.00.xdelta)에는 아래의 7개 모드 설정과 합체 스킬 수동 계승, 스킬 카드 복제 대상 선택이 들어 있습니다.

직접 보유한 한국어판 원본 ISO, `.xdelta` 패치 파일, `xdelta3`를 준비합니다. 아래는 Windows PowerShell에서 `xdelta3`를 실행할 수 있는 상태를 기준으로 한 절차입니다.

1. 원본 ISO와 패치 파일을 같은 폴더에 두고 그 폴더에서 PowerShell을 엽니다. 아래 명령의 ISO와 패치 파일 이름을 실제 파일명에 맞춥니다.
2. 원본 ISO의 SHA-256이 `09868e5bd1e659cb2b1b5ed761bb17a1ef821bc95fc7be42ec4e4d5f5964645d`인지 확인합니다.

   ```powershell
   Get-FileHash "원본.iso"
   ```

3. 패치를 적용해 새 ISO를 만듭니다. 출력 파일이 이미 있으면 다른 이름을 지정합니다.

   ```powershell
   xdelta3 -d -s "원본.iso" "p3p-kr-ucks45140-v1.00.xdelta" "p3p-kr-patched.iso"
   ```

4. 기존 세이브를 백업한 뒤 PPSSPP에서 새 ISO를 엽니다. 원래 게임으로 돌아가려면 원본 ISO를 열면 됩니다.

## 게임에서 사용하기

### 모드 설정

1. 필드에서 `COMMAND → SYSTEM → 컨피그`를 열면 좌측 하단에 `SELECT 모드 설정` 안내가 표시되고, `SELECT`를 눌러 `모드 설정`을 엽니다.
2. 위아래 방향키로 7개 항목을 이동하고 좌우 방향키 또는 `○`로 값을 바꿉니다. 한 화면에 5개씩 표시되며, 아래로 이동하면 나머지 항목이 나타납니다.
3. `×` 또는 `SELECT`를 누르면 컨피그로 돌아갑니다.

설정은 게임을 실행하는 동안 유지됩니다. 게임을 새로 실행하면 경험치와 돈은 `AUTO`, 나머지 설정은 `OFF`로 돌아갑니다.

경험치와 돈은 각각 `AUTO`, `×1.5`, `×2`, `×4`, `×8` 중 하나로 설정할 수 있습니다. `AUTO`는 게임의 기본 보상 계산을 사용합니다.

- **경험치**는 전투에서 주인공, 동료, 페르소나가 받는 경험치에 적용됩니다. 타르타로스에서 흩어진 동료가 단독 자동 전투에 이겼을 때도 적용됩니다.
- **돈**은 셔플 타임의 코인 카드 보상에 적용됩니다.
- **커뮤 랭크업 필요 호감도 0**을 켜면 호감도가 부족해도 다른 조건을 충족한 날에는 랭크업 이벤트를 진행할 수 있습니다. 쌓아 둔 호감도와 날짜·선행 조건은 원본 규칙을 따릅니다.
- **스킬 카드 복제 대기 1일**을 켜면 신사에 카드를 맡긴 다음 게임 내 날짜부터 받을 수 있습니다. 접수 대화에는 5일 안내가 표시되며, 이미 맡긴 카드에도 하루 대기가 적용됩니다. 수령 전에 끄면 원래 완료일을 따릅니다.
- **전투 아이템 드롭률 100%**를 켜면 전투에서 드롭 조건을 충족한 아이템 후보를 모아 원본 결과 화면이 지원하는 최대 3종까지 지급합니다. 후보가 3종을 초과하면 이벤트·스크립트 드롭을 최우선으로 포함하고 남는 슬롯을 일반 드롭 중에서 공평하게 무작위 선택합니다. 같은 아이템은 수량을 합산하며, 아이템별 보유 한도는 99개입니다.
- **벤치 동료 경험치**를 켜면 일반 전투에서 승리했을 때 편성 가능한 대기 동료와 흩어져 탐색 중인 동료도 설정한 배율로 경험치를 받습니다. 후카, 현재 HP가 0인 동료, 기절한 전투 참가자는 벤치 보상 대상에서 제외됩니다. 대기 동료가 레벨업하면 필드로 돌아왔을 때 화면 왼쪽 위에 이름과 레벨 변화가 표시됩니다.
- **컨디션 항상 최고조**를 켜면 주인공과 합류한 동료 전체(대기 동료 포함)의 컨디션이 즉시 `최고`로 오르고, 전투·타르타로스 탐색·기절·날짜 경과·야간 활동에서도 하락하지 않고 유지됩니다. `OFF`로 전환하면 그 시점부터 원본 규칙대로 자연 변화하며, `ON` 상태에서 세이브하면 `최고` 상태로 저장됩니다.

### 페르소나 합체 스킬 수동 계승

1. 합체 결과 미리보기에서 `○`를 눌러 계승 스킬 선택을 시작합니다.
2. 방향키로 후보와 설명을 살펴보고 `○`로 계승할 스킬을 하나씩 고릅니다. 하단에 `계승 X/Y` 진행률이 표시되며, 선택 도중 `×`를 누르면 직전 선택 1개를 되돌리고(고른 스킬이 없으면 미리보기로 복귀) 이어서 고를 수 있습니다.
3. 마지막 스킬을 고르면 합체 확인 대화가 열립니다. 여기서 합체를 확정합니다.

계승 가능한 스킬과 고를 수 있는 개수는 원본 합체 규칙을 따릅니다. 계승 후보가 없으면 기존 합체 확인 절차로 진행합니다.

### 스킬 카드 복제 대상 선택

1. 신사 사당에서 새 의뢰를 시작하면 맡길 수 있는 스킬 카드 목록이 열립니다.
2. 위아래로 카드를 고르고 좌우로 페이지를 넘깁니다(한 페이지 6종). 목록 하단에서 현재 카드의 스킬 설명과 페이지 번호를 바로 확인할 수 있으며, `○`를 누르면 확인창(`○ 맡기기 / × 취소`)이 열립니다.
3. 확인창에서 다시 `○`를 누르면 1장을 맡깁니다. 수령할 때는 같은 카드 2장을 받습니다. `×`를 누르면 확인창에서 목록으로, 목록에서 사당으로 돌아갑니다.
